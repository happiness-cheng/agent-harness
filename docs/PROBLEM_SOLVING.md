# 问题与实际处理

分步实现说明见 `docs/steps`，提交证据见 [提交说明](SUBMISSION.md)。这里保留最终交付相关的复现、取舍和限制；含本机配置的完整恢复日志不公开。

| 问题 | 复现 / 根因 | 修正与实际证据 |
| --- | --- | --- |
| OpenAI 请求失败 | 官方端点真实返回 HTTP 429 / 计费类别；输出上限不是已证实根因 | 保留诊断和适配器，按用户决定使用 DeepSeek、暂缓比较；没有读取 Codex auth |
| DeepSeek 原生推理元数据不兼容 | 已有真实 smoke 返回提供商不支持的摘要/加密字段 | 只保留 DeepSeek 支持的原生 content 协议往返；旧报告与离线回归见 S17-b |
| Runtime 新持久路径破坏旧 finish 故障合同 | 集成回归确实出现失败 | 检查点走历史/终态/检查点一起提交；旧非检查点路径保留其合同 |
| Steer 在模型返回时晚到 | 失败测试显示旧工具仍会派发 | 再检查控制事件，为旧批次补 not_started，重新让模型决策；相关测试通过 |
| Stop 与直接回答竞态 | 模型返回期间 Stop，原先仍标 completed | 保留已收到文字并标 cancelled，队列不自行启动；浏览器测试覆盖停止及定向恢复 |
| 失效 handler 返回阻塞恢复 | 非字符串返回后留下未配对 tool call | 新应用恢复模式补 returned/其余 not_started，失败后可以核对而不盲重试；旧兼容入口不改 |
| 原文 metadata 绕过上限 | raw_html 在 metadata 中未计入会话材料预算 | 原文及 metadata 一起计量；先失败的回归通过 |
| 网页代理 TLS 失败 | 固定 IP 的代理隧道把 IP 用作目标域名，证书校验失败 | 保留 TLS 和 SSRF 门，网页改用直连；Python 官方网页实际取得正文；不支持任意代理隧道 |
| 研究用尽工具而无证据收尾 | 首批真实研究 partial/budget_exhausted | 预留最后无工具输出，后续真实官方 FAQ 逐字引文通过；搜索本轮 unavailable 如实保留 |
| 摘要虚增未完成工作 | “尚未写入”被解释为“仍待写入” | 改提示词后真实合成案例 open_questions 为空；压缩后的事实与工具追问再通过 |
| 有效摘要仍无法装入窗口 | 同一源反复压缩成功但窗口仍不足 | 按原版本及输入记录失败，两次后禁止再调用模型；原始上下文版本不覆盖 |
| Windows 用户未看到测试弹窗 | 用户明确报告未见；ToastEnabled=0，原生 setting=DISABLED_FOR_USER | 不改用户系统开关；发送前检测 disabled，会话事件仍未读可见。实机显示/点击仍未通过 |
| 空消息 dispatch 不启动旧队列 | API 接受了控制但没有 worker | 增加可信派发入口，同时拒绝绕过暂停检查点；相关失败测试后通过 |
| 活动模型期间可以确认目标 | 测试证明状态能在运行中改变 | 可信入口用应用锁拒绝确认，运行中只能显式 Steer；原提案不被静默授权 |
| Memory 返回无关记录 | 只有一条归档时无关问题仍得到该摘要 | 过滤零相关得分；单 session 受控引用与完整交互保留 |
| 浏览器截图捕获淡入与移动端过渡 | 早期截图消息过淡、导航处于过渡中 | 截图完成有限动画，断言移动导航打开/关闭及无横向溢出；不把瞬时截图当稳定布局 |
| 搜索库静默改用其他引擎 | 实际安装的 Bing.disabled=True，DDGS 对缺失后端自动回退；其他入口也有空结果、限流、校验页 | 固定 HTTPX 请求 Bing 搜索页，复用解析组件，不自动换引擎；Python 查询实际返回 Python 官方站。完全无查询词的结果拒绝，SQLite 查询无关结果保留为失败证据 |
| Python 官网忽略 identity，返回 gzip | 真实研究选中搜索结果里的官网，但读取失败；独立请求确认 Content-Encoding=gzip | 先复现 gzip/高压缩比边界，再采用 zlib.decompress(max_length)，同时限制压缩输入与解压输出；真实正文提取通过 |
| 两次搜索触发过早收尾 | 工具预算 4，一次响应含两次搜索，剩 2 就撤去工具，无法读取 | 阈值改为剩 1；同时硬拒绝收尾继续调用工具，模型额度仍预留最后一轮。失败报告保留，离线两次搜索→读取回归通过 |

最后两次真实模型请求复用已实际取得的搜索结果，由模型选中 Python 官网、真实读取并返回逐字引文。它是续接核验，不能描述为“一次全新搜索闭环全部通过”。32 次本批额度已经用完，不自动续费复跑；详细区分见验收文档。

未配置 Type/Lint；TestClient 发出 Starlette/HTTPX deprecation 警告，当前测试通过，未擅自换 HTTP 适配器。搜索无 SLA，静态数据未加密，多进程同时写入同一工作库不受支持。没有自动提交、推送、系统通知开关修改或数据库 schema 迁移。
