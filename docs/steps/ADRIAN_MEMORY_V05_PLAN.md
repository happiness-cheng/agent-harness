## 评分和归因

原书precision/recall/reasoning/proactivity 1～4级rubric保留，需真实回答和源审判断后才填。事实准确率、实体/情景、时间状态、当前指令冲突、捏造引用、证据自报分别记录；证据自报不证明模型内部因果使用。

自动字段只有可解释代理：原事实表面覆盖、引用存在/是否可见、JSON格式、精确已审控制条件；不冒充全面语义准确率或原书Judge。未知/未审不算错误也不算正确。语义评分通过绑定answer hash的审查表导入，必须带回答/源原句证据，禁止根据输出改Gold。

STORAGE/RETRIEVAL/RANKING/PACKING用源事实合法存在、候选、最终排名、实际注入材料区分。REASONING/CONFLICT必须有真实回答与经过源审的判断；EVALUATION用于外部规则、争议Gold/等价证据。网络/格式/输出截断单独记录执行失败，不伪装成记忆失败。允许多标签和UNKNOWN，不强行给唯一原因。
