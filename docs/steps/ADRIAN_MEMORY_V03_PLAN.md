# Adrian Memory v0.3：固定实验计划与自审

用户正式任务书授权实施。沿用实际 v0.2 工作区，不改既有 source/报告，不更换分支或推送，不改生产检索/Runtime/Goal 权重/数据库。不调用外部模型、不读或导入私人行为数据。

## P0：冻结

- 用 v0.2 delivery-receipt 核对全部实验源码；分别保留旧原文修复与检索实验的文件/hash。
- 原 8 题与 v0.2 的 6 题均为本轮已见开发材料。
- 新保留测试：从余下 46 题按每层文件名排序，各选前 2 题；在运行新检索前按原始证据制作有位置/hash的 Gold。不是独立专家盲评，不是原书完整任务评分。
- 原书 60 题、旧 Gold 和所有旧输出不改。争议事实继续单独审计。

## P1/P2：隔离变量

- A=原 cap=100 候选、原分数；B=同一批候选、实验排序；C=改进候选、原分数；D=改进候选、实验排序。
- Top-K=8，模型可见预算=2048 UTF-8 紧凑序列化字节，复用 v0.2 整条装入函数；各组原文内容/权限/时间/评分相同。精确 Token 与模型任务质量 NOT_RUN。
- 实验排序：授权历史上的查询关键词 IDF 覆盖；同事件相邻原句支持；通用属性类型匹配；明确标识符/数值及实体匹配；问句惩罚；保留原始分数作小权重信号。无 case ID/Gold/特定人名金额。
- 冻结线性权重：原句关键词 2、相邻关键词 1、属性且有取值 1、相关具体取值 0.75、精确实体 2、原分数 0.2、问句 -0.6。
- 改进候选：通用属性词族扩展与历史中显式 Name (ALIAS)；原路径、扩展 FTS、同事件相邻 ±1 消息三路按每路唯一 ID 的 RRF(k=60) 分配同一 cap=100。相邻锚点每条词项路径最多 12。不扩大最终上限，不把 RRF 分数冒称原排序分数。
- C 的旧分数：保留原始检索同 ID 的完整融合分数；新词项候选采用同一旧 _lookup 在原查询上的分数；完全无原词命中的邻居为 0。不偷偷让 C 使用新排序器。
- 候选构建和排序都只用截至 as_of 的授权原文与证据，不追加到模型正文。追踪扩展词/锚点/特征贡献/融合路径。

## P3：原子卡片单独验证

主体、属性、取值都必须引用原文字符片段；跨句关联必须同一事件，推断关联保留 inferred，批准仅为 Fixture。测试同名不同事件、伪造取值、未来来源、未确认状态；另用原 Amex 对话构建带原始片段的上下文关联卡。不得从 Gold 创建缺失事实。不向生产写入，不参与 A/B/C/D。

## P4/P5：判据与停止规则

- 同时报告每题/宏平均/事实总数：Candidate Recall、Recall@8、预算可见覆盖、延迟、cap 前后数量、去重及来源路径。保留退化。
- 已见 14 题和新测试 6 题分层报告。验证 A 与 v0.2 对应 14 题 ID/指标一致，B 的候选 ID 集与 A 一致，C/D 的候选集一致。
- 合成契约先 RED/GREEN；固定算法/Gold/hash后仅一轮20题对照，不按测试结果改规则或调权重。错误实现允许独立复现后修复，保留失败证据。
- 完成原安全/Runtime 完整回归、构建/编译/依赖/差异自审，保存准确版本与补丁。缺工具的静态检查标 NOT_RUN。
- 交付三份报告和原始输出后停止。即使有收益也不自动启用默认策略。

方案自审：比较了不加新模型的透明规则、付费 reranker、卡片替代三种路径；本轮选透明规则以隔离变量和成本，另两种不影响默认行为。按用户指引主代理自审，不调用子代理。
