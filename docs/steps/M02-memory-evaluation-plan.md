# M02：先安排Memory评测

## 目标与范围

作者确认：同一用户跨会话记忆是核心，不同用户必须严格隔离。Memory应在合适的时候提供合适的信息，支持第二大脑的连续理解、可靠回忆和有依据的主动帮助。

本轮只做评测样本、标准、离线反馈回路和当前召回基线；不修改MemoryJournal、Runtime、记忆写入或跨会话权限。State Bar保持收尾。无需额外确认已经授权的本地评测建设。无外部模型调用，不读取凭据；不借用历史已耗尽额度。

## 评测包

1. 保留书中原集为外部公共参照，生成60例清单、逐文件SHA256和实际数据统计。参考题中的外部法律/医疗/旅行规则需另行核验，不直接当成记忆真值。本轮不复现其在线评分。
2. 自建32个纯合成案例，8类各4：显式回忆、时间更新、语境消歧、跨会话综合、按需提供、保留/遗忘、归属/事实边界、长历史/鲁棒性。
3. 每类2开发+2公开固定验收，合计16+16；不是盲测。第一次基线前冻结输入与期望。发现新反例另增回归，不改旧标准凑通过。
4. 输入与gold分离；模型输入只包含授权范围内、问题时点以前的历史及本轮问题，不能包含答案、判据或未来会话。
5. 检索层使用固定retrieval_query，不评价模型构造查询的能力；回答阶段另用完整用户问题。时机、最新性、事实归属、主动帮助及拒绝臆测由独立语义评测处理。

## 分阶段标准

- 写入：以后评是否应记、是否保存正确事实/归属/时间/纠正关系，敏感及不记指令是否遵守。当前只验证原始归档存在，不冒充语义记忆写入。
- 召回：required_evidence覆盖、allowed_evidence精度、无关及禁止来源、是否本来无需记忆。只计实际返回来源，不把全库内容当召回命中。
- 提供：以后记录实际模型可见材料、必要信息完整性、字节/Token、被压缩前后的变化；当前未运行模型上下文投递。
- 使用：事实精确、必要信息覆盖、消歧/时间推理、恰当主动帮助四维1—4级；普通直接回答不强求额外建议。无依据重要事实、跨用户泄漏、遗忘后泄漏、记忆冒充授权等硬错误否决，平均分不能抵消。
- 成本：分别记录写入/检索/投递/回答/裁判的调用、真实usage和耗时。离线材料只记录字节，不冒充Token或费用。

## 离线基线与证据边界

使用无记忆、真实legacy_current_session和full_history_diagnostic三个对照。后者只按用户/时间/会话范围过滤，故意暴露全历史的噪声及遗忘问题，不是安全生产方案，也不是满分oracle。以同一案例比较，不用gold帮助检索。

另设真实当前会话召回阳性控制及SQLite重开控制，确认不是入口坏了。空检索未泄露不能证明具备跨会话隔离或遗忘；负向安全结论注明未充分触达。跨会话当前无返回如实计为能力未实现，不能包装成模型记忆准确率。
