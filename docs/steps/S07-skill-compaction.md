# S07 小结：先筛选 Skill，再整理历史

日期：2026-10-23。[完整提示词、差异、代码、输入对比与故障记录](S07-readable.md)。

## 实现的流程

窗口有压力 → 筛选已加载的最近成功版本 → 校验完整分区 → keep/uncertain原文保留，release移出工作材料 → 必要时压缩普通历史 → 检查完整请求预算。

原文放在独立快照中；近期Skill工具结果变成保留调用ID的读取记录；普通历史压缩也使用不含正文的投影。原始历史和归档保留全文。旧状态仍兼容S06恢复逻辑；新流程不再用index判断适用性。

## 关键取舍

- 只在需要整理上下文时调用筛选，不每轮调用。与主模型共用预算、Stop和模型实例；筛选没有工具，不执行返回的工具请求。
- 模型只选择ID，不能改写正文。未知/遗漏/重复ID或额外字段使整个选择无效，保守保留；预算/输入窗口不足时不发筛选请求。
- 停用状态跨管理器重建保留，新显式读取默认重新激活，下次窗口整理可重评。准备失败不提交新的选择。
- 选择依据暂为已有摘要与最近两个用户交互范围；可能缺背景，需真实评测。旧摘要中的规程摘录不自动迁移清洗。
