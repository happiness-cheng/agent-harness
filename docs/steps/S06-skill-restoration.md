- 同名取最近一次成功读取，保留正文、内容哈希、工具调用 ID；新读取失败不替换旧成功版本。
- 最近全文还在近期交互里时不额外放快照；原始历史不改，不伪造工具调用。
- 全文与包装计入窗口预算，放不下就停止，不悄悄截断。
