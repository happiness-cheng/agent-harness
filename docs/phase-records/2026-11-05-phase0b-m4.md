## 做了什么与取舍

[activity_changes.py](../../src/min_agent/activity_changes.py) 比较已接受基线及两次读取证据，严格按 unstable_read → truncation → migration → compression_change → append → semantic_rewrite 分类。Schema 是版本、结构键集合、序号空间，独立于压缩编码；物理与解压长度/hash 分开计算。缺 Schema、缺重写证据或矛盾编码证据均 unresolved；完全未变化返回 unresolved/unchanged，保留位点且不冻结。

Semantic Rewrite 只在 Schema 相同且前缀不成立时允许，需平台显式标记或完整换行记录的多重集相同但次序变化。重复记录数量也必须相同，不用集合去重猜重排。

不可变合成执行器复用现有 derive/object_identity，实际生成 ID、追加快照和观察、关闭旧 Checkpoint 并为新 Member/Generation 建位点 0。每条观察保留两次读取样本、证据 hash 和是否执行。固定 observation_id 可重放，异证据复用 ID 或陈旧 Snapshot 拒绝。

选择独立执行器是因为 M3 Store 当前为单 Member/未压缩实验格式；本轮不为压缩/迁移重构整个 Store。**该执行器仅内存，不是持久 Store 接线**。M1–M3 源码未改。

## 实际副作用验收

| 分类/场景 | 身份与 Checkpoint 实际结果 |
|---|---|
| unstable_read / truncation | 无新 Member/Generation/Snapshot；保留观察，位点不动，后续自动身份切换被阻止 |
| migration | 新 Member/Generation/Checkpoint，旧身份保留、旧位点 closed，新位点 0 |
| compression_change / append | Member/Generation/root 不变，新 Snapshot、latest 前进，位点保持 |
| semantic_rewrite | 同 Member，新 Generation derived_from 旧代，旧位点 closed，新位点 0 |
| unresolved 缺证据 | 无身份变更/位点推进，保守阻塞后续执行 |
| 旧代未消费完 | 返回分类并记录阻塞，不执行新 Member/Generation |
| 压缩切回原表示 | 复用原 Snapshot ID，latest 指回原快照，不重复注册 |

测试还覆盖 schema 的三种变化与 append/rewrite/encoding 交叉优先级、物理变短而逻辑 append、物理变长而逻辑 truncation、未结束 zstd 流、双读不一致和实际临时合成文件。
