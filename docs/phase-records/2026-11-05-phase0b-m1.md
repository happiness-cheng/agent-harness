核心路径：

```python
bundle = self._load(conn)
model = _validate(bundle)       # 先检查 ID 绑定、哈希链、状态和位点
yield bundle, model            # 本次变更发生在同一 SQLite 事务内
if write:
    _validate(bundle)          # 提交前再验证候选内容
    self._persist(conn, bundle, before)
```

像先核对账簿上一页和页码，再记下一页；身份页与日常观察分开，新增观察不会重编号身份。root 固定在 generation 注册项，latest 从 Observation 链取最后快照，状态由事件折叠。
