## 实现及原因

- [activity_m2.py](../../src/min_agent/activity_m2.py)：独立实验 Store；合成完整换行记录按 generation/stream/ordinal 确定键，幂等写入提交后才能 CAS 推进 Checkpoint。位点推进会检查整个覆盖区间的事件已提交。
- [activity_store.py](../../src/min_agent/activity_store.py)：仅提取共享 Manifest 校验，保留 M1 行为。
- [test_activity_m2.py](../../tests/unit/test_activity_m2.py)：实际 SQLite 文件、重开连接、子进程退出、独立读者和并发写入验证。

转换的实际事务边界为：

```python
conn.execute("BEGIN IMMEDIATE")
# 同一 conn 写入 Manifest 新代、Observation 状态历史、Checkpoint。
# pending、旧 closed、新 active、committed 均在该事务内。
self._persist_m2(conn, bundle, previous, operation)
conn.commit()
```

这不是多次公开写 API 的顺序调用。身份与状态历史只追加，旧代与旧位点保留；同 transition_id 同参数返回原生成身份，异参数拒绝。新代位点为 0；旧代必须消费完毕，避免切换后留下未消费记录。并发依靠 SQLite 写锁和旧 Checkpoint revision/hash CAS。
