# 读代码先定位入口

目标：用最少阅读建立「请求从哪里进、经过哪些模块、在哪里落地」的可验证调用链，再深入实现。

## 步骤

1. **找入口**：先查启动与注册点——`pyproject.toml` 的 scripts/入口、`__main__.py`、
   应用工厂（如 `create_app`）、工具/路由注册处。入口是事实，不是猜测。
2. **画调用链**：从入口沿 import 与函数调用往下走，只记录真实存在的边；
   区分「import 时加载」与「函数内懒加载」——后者不代表死代码，前者不代表被调用。
3. **定点深读**：只精读与任务相关的分支；每读一段，写清它解决什么、输入输出是什么。
4. **留证据**：结论附文件路径与行号；用 grep/测试验证调用关系，不把「看起来像」当成已验证。

## 边界

- 本技能不授权修改代码；读到权限、凭据、删除逻辑时先停下核对授权。
- 调用链结论只覆盖实际读过的路径；未读分支明确标未验证。
